# Context Directory

This directory is used for storing LLM (Large Language Model) context files.

## Purpose

Store files that you want to provide as context to AI assistants, such as:

- **Code examples** - Reference implementations or patterns
- **Image files** - Screenshots, diagrams, mockups
- **Documentation snippets** - Relevant docs for AI to reference
- **Prompts** - System prompts or instruction templates
- **Reference materials** - Any other context that helps AI understand the project

## Note

This directory is gitignored (except for this README) to keep context files local and prevent cluttering the repository with potentially large or sensitive context materials.
