1. Scope of the calculator

The calculator estimates ROI for AR-based SOP projects (ActARion / DeepSight style) from:

Faster onboarding and training

Fewer errors / scrap / rework

Less unplanned downtime

Reduced travel and on-site support (remote expert)

Costs: licenses, hardware, implementation, content creation & maintenance

You typically calculate over 3 years with one “steady-state” year as reference.

2. Core inputs (assumptions)

I’ll keep the variable names so you can copy them into Excel.

Workforce & usage

N_op = number of operators working with the SOPs

N_new = number of new operators per year

SOP_count = number of critical SOPs supported by AR

Training & labor

H_train_base = training hours per new operator today (for the SOP set)

H_train_AR = training hours per new operator with AR

C_hour_op = fully loaded hourly cost of an operator

C_hour_trainer = fully loaded hourly cost of trainer/SME

Errors & quality

Exec_per_op_per_year = number of SOP executions per operator per year (for these SOPs)

Error_rate_base = current error probability per SOP execution (%)

Error_rate_AR = error probability with AR (%)

Cost_per_error = average cost per error (scrap, rework, lost batch, extra QC, downtime, etc.)

Downtime / throughput

H_downtime_base_per_year = hours of unplanned downtime per year due to SOP-related issues

Downtime_reduction_pct = % reduction of that downtime with AR

Cost_per_downtime_hour = cost per hour of downtime (lost margin, OEE impact)

Remote support / travel

Visits_per_year = number of on-site troubleshooting/training visits per year (SME/vendor)

Cost_per_visit = cost per visit (travel + time)

Visit_reduction_pct = % reduction of visits with remote expert & AR

AR solution costs (ActARion / DeepSight)

C_license_user_year = annual license cost per user

N_users = number of users (authors + viewers)

C_license_site_year = fixed license cost per site per year (optional)

N_sites = number of sites

C_device_per_user = device investment per user (tablet / smart glasses)

N_devices = number of devices

Device_lifetime_years = hardware lifetime in years

Implementation_one_time = one-time implementation cost (ActARion + internal)

Content_initial = one-time cost to convert initial SOPs into AR workflows

Content_annual = annual cost to keep content up to date

Internal_PM_hours = internal project management hours per year

Internal_PM_rate = hourly rate of internal project manager

Financial

Horizon_years = business case horizon (e.g. 3 years)

Discount_rate = discount rate for NPV (e.g. 8–10%)

Adoption_year1, Adoption_year2, Adoption_year3 = adoption level per year (e.g. 0.6, 0.8, 1.0)

3. Benefit formulas
3.1 Training time and cost

Annual training hours saved

Training_hours_saved = N_new * (H_train_base - H_train_AR)

Annual training cost savings (€)

Training_savings = Training_hours_saved * (C_hour_op + C_hour_trainer)

You can refine this if only part of operator time is considered “lost”, but for a first business case this is usually acceptable.

3.2 Fewer errors / scrap / rework

Total SOP executions per year

Total_executions = N_op * Exec_per_op_per_year

Errors per year today

Errors_base = Total_executions * Error_rate_base

Errors per year with AR

Errors_AR = Total_executions * Error_rate_AR

Avoided errors per year

Errors_avoided = Errors_base - Errors_AR

Annual quality savings (€)

Quality_savings = Errors_avoided * Cost_per_error

3.3 Less SOP-related downtime

Downtime hours saved

Downtime_hours_saved = H_downtime_base_per_year * Downtime_reduction_pct

Downtime savings (€)

Downtime_savings = Downtime_hours_saved * Cost_per_downtime_hour

3.4 Fewer on-site visits (remote expert)

Visits avoided per year

Visits_avoided = Visits_per_year * Visit_reduction_pct

Travel/support savings (€)

Remote_savings = Visits_avoided * Cost_per_visit

3.5 Total annual benefits

Steady state (full adoption):

Total_annual_benefits = Training_savings + Quality_savings + Downtime_savings + Remote_savings

With adoption per year:

Year 1: Benefits_Y1 = Total_annual_benefits * Adoption_year1

Year 2: Benefits_Y2 = Total_annual_benefits * Adoption_year2

Year 3: Benefits_Y3 = Total_annual_benefits * Adoption_year3

4. Cost formulas
4.1 Software

Annual license costs

Software_annual = (C_license_user_year * N_users) + (C_license_site_year * N_sites)

4.2 Hardware

Annual hardware cost (depreciation)

Hardware_annual = (C_device_per_user * N_devices) / Device_lifetime_years

4.3 Implementation and content

One-time in year 0

One_time_costs_Y0 = Implementation_one_time + Content_initial

Annual content & internal time

Internal_PM_annual = Internal_PM_hours * Internal_PM_rate

Opex_annual = Content_annual + Internal_PM_annual

4.4 Total annual costs

Steady state annual costs:

Total_annual_costs = Software_annual + Hardware_annual + Opex_annual

Per year:

Year 0: Costs_Y0 = One_time_costs_Y0 + Total_annual_costs * Adoption_year1 (optionally start licenses from go-live)

Year 1: Costs_Y1 = Total_annual_costs

Year 2: Costs_Y2 = Total_annual_costs

Year 3: Costs_Y3 = Total_annual_costs

(If you want licenses to scale with adoption, multiply by adoption factor per year.)

5. ROI metrics
5.1 Annual net benefit (steady state)

Net_annual_steady = Total_annual_benefits - Total_annual_costs

5.2 Payback period (simple)

If you assume you reach steady state quickly:

Payback_years ≈ One_time_costs_Y0 / Net_annual_steady

For a more precise view, use yearly cashflows:

Year 0: CF0 = -Costs_Y0

Year 1: CF1 = Benefits_Y1 - Costs_Y1

Year 2: CF2 = Benefits_Y2 - Costs_Y2

Year 3: CF3 = Benefits_Y3 - Costs_Y3

Cumulative:

Cum_CF_Y0 = CF0

Cum_CF_Y1 = CF0 + CF1

Cum_CF_Y2 = CF0 + CF1 + CF2

etc.

Payback is where cumulative cashflow turns from negative to positive.

5.3 Simple ROI over the horizon

Over 3 years:

Total_benefits_3Y = Benefits_Y1 + Benefits_Y2 + Benefits_Y3
Total_costs_3Y = Costs_Y0 + Costs_Y1 + Costs_Y2 + Costs_Y3

Simple ROI (%)

ROI_3Y = (Total_benefits_3Y - Total_costs_3Y) / Total_costs_3Y

5.4 NPV (optional)

With discount rate Discount_rate (e.g. 0.08):

NPV = CF0 / (1+Discount_rate)^0 + CF1 / (1+Discount_rate)^1 + CF2 / (1+Discount_rate)^2 + CF3 / (1+Discount_rate)^3

6. Suggested Excel structure

You can put this in one sheet:

Block A – Inputs
Rows 2–25: all variables from section 2, with values in column B.

Block B – Benefits
Compute:

Training_savings

Quality_savings

Downtime_savings

Remote_savings

Total_annual_benefits

Block C – Costs
Compute:

Software_annual

Hardware_annual

Opex_annual

Total_annual_costs

One_time_costs_Y0

Block D – Yearly cashflow (0–3)
Columns: Year, Benefits, Costs, Net, Cumulative, Discounted.

Block E – KPIs

Net_annual_steady

Payback_years

ROI_3Y

NPV
