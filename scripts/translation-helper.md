# Translation Helper Guide

## Current Status
- Completed: 6 files (3 posts fully translated)

## Translation Checklist Per Post
1. Read English post
2. Create NL version: `filename-nl.mdx`
   - Translate frontmatter (title, description, tags)
   - Set `locale: "nl"`
   - Translate body content
   - Update internal links: `/en/` → `/nl/`
3. Create DE version: `filename-de.mdx`
   - Translate frontmatter (title, description, tags)
   - Set `locale: "de"`
   - Translate body content
   - Update internal links: `/en/` → `/de/`

## Key Points
- Keep same slug for all locales
- Preserve structure (headings, lists, formatting)
- Keep external links unchanged
- Translate product names only if appropriate
- Maintain professional, technical tone
