# ActARion Blog Hero Image Guidelines

## Overview
This document defines the visual style and specifications for ActARion blog post hero images. All images should maintain brand consistency while clearly communicating the specific topic of each article.

---

## Visual Style

### Two Approved Styles

**Style A: Vector/Illustrated (Preferred)**
- Flat, modern vector illustration style
- Clean lines with minimal texture
- Industrial/manufacturing setting backgrounds
- Workers shown in profile or three-quarter view

**Style B: Photo-realistic (Alternative)**
- Blue-tinted photographic imagery
- Professional industrial photography aesthetic
- Workers in authentic manufacturing environments
- Shallow depth of field with subject focus

---

## Color Palette

### Primary Colors
| Color | Hex Code | Usage |
|-------|----------|-------|
| ActARion Teal | `#3B9ECF` | Primary brand color, backgrounds |
| Navy Blue | `#1A3A4A` | Equipment, machinery, dark elements |
| Light Cyan | `#D4EEF5` | Background gradients, AR overlays |

### Accent Colors
| Color | Hex Code | Usage |
|-------|----------|-------|
| Orange | `#F58345` | Arrows, highlights, warning indicators |
| White | `#FFFFFF` | Checkmarks, text overlays, UI elements |
| Soft Teal | `#7BC4D9` | Secondary highlights, soft accents |

---

## Required Elements

### 1. Industrial Worker(s)
- Hard hat or safety helmet (teal or orange)
- Safety glasses or AR smart glasses
- High-visibility vest or industrial workwear
- Professional, focused expression
- Gender-diverse representation across images

### 2. Industrial Equipment
- Machinery (motors, pumps, conveyors, assembly lines)
- Pipes and industrial infrastructure
- Control panels and monitoring screens
- Equipment appropriate to the article topic

### 3. AR Overlay Elements
- Floating checklist panels with checkmarks
- Gear/settings icons
- Warning triangles (orange fill)
- Step-by-step instruction boxes
- Orange directional arrows pointing to equipment
- Digital annotation markers

### 4. Devices (as appropriate)
- Tablets held by workers
- Smartphones
- AR headsets (HoloLens-style)
- Smart glasses

---

## Image Specifications

### Dimensions
- **Width:** 1200px minimum, 1920px recommended
- **Height:** 630px minimum (16:9 aspect ratio preferred)
- **Format:** PNG with transparent background option, or JPG for photos

### File Naming Convention
```
{topic-slug}-hero.png
```
Example: `ar-assembly-checklist-hero.png`

### File Location
All blog hero images should be placed in:
```
public/blogs/
```

---

## Composition Guidelines

### Layout
- Worker positioned on right side (60% of images) or left side
- Equipment/machinery as focal point or background
- AR overlays floating between worker and equipment
- Clean, uncluttered backgrounds with industrial context

### Spacing
- Subject should not be cropped at the head
- Leave 10-15% padding from edges
- AR elements should not obscure key subjects

### Text Overlay (Optional)
- If including title text, use bold sans-serif font
- Place in upper portion of image
- Teal color for text: `#3B9ECF`
- Max 2 lines of text

## Topic-Specific Visual Themes

| Topic Category | Key Visual Elements |
|----------------|---------------------|
| **Assembly** | Production line, component parts, step sequence arrows |
| **Onboarding/Training** | New worker learning, mentor presence, learning checklist |
| **Maintenance** | Equipment internals, tools, diagnostic overlays |
| **Safety** | Warning icons, lockout/tagout, safety checklists |
| **Quality/Inspection** | Magnifying elements, pass/fail indicators, audit clipboards |
| **Logistics** | Warehouse setting, picking bins, shipping boxes |
| **Remote Support** | Video call UI, remote expert on screen, live annotations |
| **ROI/Business** | Charts, cost indicators, time savings visualizations |

---

## Examples

### Good Example
✅ Worker in teal hard hat and safety glasses
✅ Industrial motor/pump in background
✅ AR checklist overlay with orange checkmarks
✅ Orange arrows pointing to equipment parts
✅ Light cyan gradient background

### What to Avoid
❌ Generic stock photos without industrial context
❌ Overly busy compositions with too many elements
❌ Colors outside the defined palette
❌ Low-resolution or pixelated images
❌ Images without any AR/digital overlay elements

---

## Image Generation Prompts

For AI image generation tools (Midjourney, DALL-E, etc.), use this base prompt structure:

```
Flat vector illustration, industrial manufacturing worker in [teal/orange] hard hat 
and safety glasses, standing next to [EQUIPMENT TYPE], holding tablet, AR overlay 
showing [OVERLAY TYPE], teal and cyan color palette with orange accents, clean 
modern style, professional industrial setting, --ar 16:9
```

---

## Quality Checklist

Before finalizing any hero image, verify:

- [ ] Colors match the ActARion palette
- [ ] Worker shown in professional industrial attire
- [ ] AR/digital overlay elements present
- [ ] Topic-relevant equipment or setting visible
- [ ] Image is high resolution (minimum 1200x630)
- [ ] File named correctly: `{slug}-hero.png`
- [ ] Placed in `public/blogs/` directory
- [ ] Frontmatter `image` path updated in corresponding MDX file
