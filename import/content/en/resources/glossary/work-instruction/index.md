# What Is a Work Instruction? Definition

> A work instruction is a detailed, step-by-step description of how one specific task is performed at the workstation, including tools, settings and checks. It sits below the SOP. Actarion turns work instructions into digital, AR-guided steps on tablets or AR glasses, with every execution logged.

![Pen drawing for the glossary term work instruction: tablet on a stand showing a work instruction step](/img/illustraties/resources-glossary-work-instruction.svg)

## Why does it matter on the shop floor?

- Text-heavy instructions are skipped or misread.
- New operators depend on a buddy to learn the task.

## What is a work instruction?

A work instruction is a document that tells an operator exactly how to perform one task, step by step. It names tools, parts, settings, quality checks and safety points.

Where an SOP sets the process, the work instruction shows the hands-on detail. Good instructions use short steps, one action per step and visuals. Digital work instructions add checks, media and a record of each execution.

## Key elements

1. One action per step
2. Visual per step (photo, video or AR marker)
3. Check or confirmation at critical points

## Example from the shop floor

An assembly line has a work instruction for fitting a gearbox cover: 12 steps, bolt order, torque values and a final visual check.

## FAQ

### Is a work instruction the same as an SOP?

No. The SOP covers the process; the work instruction covers one task in detail.

### What makes a good work instruction?

Short steps, one action each, clear visuals and checks at critical points.

### Can work instructions be digital?

Yes. Digital work instructions run on tablets or AR glasses and log each step.
