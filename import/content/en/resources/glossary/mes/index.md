# What Is an MES? Manufacturing Execution System

> An MES, or manufacturing execution system, is software that manages and records production on the shop floor: orders, materials, machine status, quality data and traceability. It links ERP planning to the line. Actarion complements an MES with AR-guided work instructions and step-level data on how tasks were done.

![A technician holds an iPad up to a control room; the screen shows AR work instruction steps for what is an mes](/images/resources-glossary-mes-1600.webp)

## Why does it matter on the shop floor?

- The MES knows the order, but not how the operator did the task.
- Instructions in the MES are text-only.

## What is an MES?

An MES is an information system that tracks and documents the conversion of raw materials into finished goods, in real time.

Typical MES functions are order dispatch, data collection, quality management, traceability and performance analysis such as OEE. The standard ISA-95 places MES between ERP and machine control.

## Key elements

1. ERP plans the order
2. MES dispatches and tracks it on the line
3. Connected worker tools guide the manual tasks

## Example from the shop floor

The MES releases an order to line 2 and records batch and output. The operator follows the changeover instruction on a tablet before starting.

## FAQ

### Is an MES the same as ERP?

No. ERP plans the business; MES runs and records the shop floor.

### Does an MES include work instructions?

Some do, often basic. Dedicated tools add media, AR and training.

### What is ISA-95?

An international standard for integrating enterprise and control systems.
