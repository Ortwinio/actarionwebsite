# Work Instruction Template: Free, Complete and With an Example

> A work instruction template is a fixed format that describes one task step by step: what to do, how to do it and why it matters. This free work instruction template contains a header, safety and tools section, a step table with key points, quality checks and sign-off. Actarion turns completed instructions into AR-guided digital steps.

![Pen drawing of a work instruction template on a clipboard next to a tablet showing the same steps digitally](/img/illustraties/resources-templates-work-instruction-template.svg)

## Why do work instructions get ignored?

- They are written as long text blocks that nobody reads at the machine.
- Each shift does the task slightly differently, so quality varies.
- The instruction is outdated after the last machine change.
- New operators still need a buddy for weeks.

## What is a work instruction, and when do you use one?

A work instruction is a document that describes **how** one specific task is done. An SOP describes **what** happens in a process and who is responsible (see the [SOP template](/en/resources/templates/sop-template/)). Use a work instruction for any task where a mistake causes scrap, downtime or injury, or where new people need to learn it fast.

## How do you fill in each section?

1. **Header:** one task per instruction. Use a document number and version so you can prove which version was in use.
2. **Safety:** list PPE and hazards before the first step. Reference the machine's [lockout/tagout procedure](/en/resources/templates/lockout-tagout-procedure/) if energy isolation is needed.
3. **Major step:** start with a verb, keep it under 10 words. Aim for 5 to 15 steps; split longer tasks.
4. **Key points:** anything that makes or breaks safety, quality or ease of work. This is where the expert's know-how goes.
5. **Reason:** explain why a key point matters. People skip what they don't understand.
6. **Visual:** one photo or sketch per step, taken from the operator's point of view.
7. **Quality checks:** measurable criteria with the gauge to use, not "check visually".

This structure follows the classic TWI job breakdown (Training Within Industry): major steps, key points, reasons. Read the full guide on [how to write work instructions](/en/blog/how-to-write-work-instructions/).

## Example: replacing a conveyor belt scraper

| # | Major step | Key points | Reason |
|---|---|---|---|
| 1 | Stop and lock out conveyor | Main switch off, own padlock, try-start | Prevents unexpected start-up |
| 2 | Remove scraper holder | Two M10 bolts, 17 mm socket | Holder is reused |
| 3 | Fit new scraper blade | Bevel facing belt direction | Wrong side damages belt |
| 4 | Set blade pressure | 2 mm gap with feeler gauge | Too tight wears belt |
| 5 | Remove lock and test run | Check for noise, 1 minute | Confirms correct fit |

## FAQ

### What is the difference between a work instruction and an SOP?
An SOP describes the process, roles and responsibilities. A work instruction describes how one task is carried out, step by step.

### How many steps should a work instruction have?
Usually 5 to 15. If you need more, split the task into separate instructions.

### Should a work instruction include photos?
Yes. One clear photo per step from the operator's viewpoint reduces errors more than extra text.

### Who should write the work instruction?
The most experienced operator together with an engineer or team leader. Then test it with someone new.
