# SMED Checklist: Free Changeover Template for Faster Setups

> A SMED checklist makes sure everything needed for a changeover is ready before the machine stops, and that each changeover follows the same sequence. SMED (Single-Minute Exchange of Die) separates internal work, done while the machine is stopped, from external work, done while it runs. This free SMED checklist covers both, plus an analysis sheet.

![Pen drawing of a press with a die change cart, a stopwatch and a tablet showing the SMED checklist](/img/illustraties/resources-templates-smed-changeover-checklist.svg)

## Why do changeovers take longer than planned?

- The operator walks away to find tools, parts or the right settings.
- Each shift changes over in a different order.
- The first products after the changeover are scrap because of trial-and-error adjustments.
- Nobody measures the real changeover time, so nobody improves it.

## What is SMED and when do you use this checklist?

SMED is a lean method developed by Shigeo Shingo to cut changeover time. Its steps: record the current changeover, separate internal and external work, convert internal to external, streamline the remaining internal work, and standardize. Use the analysis sheet once per machine to improve the changeover. Use the checklist at every changeover to keep the gains. The full method is in our [SMED guide](/en/blog/smed-guide/).

## Part 2: Changeover checklist

**Header:** Machine ______ · From product ______ → To product ______ · Operator ______ · Date ______

**Before the stop (external, machine still running)**

- [ ] Next order, product specification and settings sheet ready
- [ ] Tools, dies or change parts at the machine, cleaned and checked
- [ ] Materials, packaging and labels for the next order staged
- [ ] Gauges and first-article inspection form ready
- [ ] Preheating or presetting of tooling done, where applicable
- [ ] Changeover team and team leader informed of start time

**During the stop (internal)**

| # | Step | Standard | Time | Done |
|---|---|---|---|---|
| 1 | Stop machine, make safe (lockout if required) | Per LOTO procedure | | [ ] |
| 2 | Remove remaining product and materials of previous order | Line empty | | [ ] |
| 3 | Remove old tooling / change parts | Quick-release clamps | | [ ] |
| 4 | Clean contact areas | Per cleaning standard | | [ ] |
| 5 | Fit new tooling with locating pins | No adjustment needed | | [ ] |
| 6 | Load settings / recipe | Settings sheet | | [ ] |
| 7 | Remove lock, start machine | | | [ ] |

**After the stop (external)**

- [ ] First article produced and approved (form no. ______)
- [ ] Old tooling cleaned, inspected and returned to storage
- [ ] Changeover time recorded: machine stop ____ → first good product ____ = ____ min
- [ ] Problems and improvement ideas noted

## How do you fill in the checklist?

1. **Analysis sheet:** film or time one full changeover. List every activity, however small.
2. **Internal / External:** ask for each activity "must the machine be stopped for this?" If not, it is external.
3. **Before the stop:** this is where most gains are. Make it a fixed trigger, e.g. 30 minutes before end of order.
4. **During the stop:** keep the internal steps in a fixed order. Add your machine-specific standards.
5. **Changeover time:** measure from last good product to first good product at full speed.

## FAQ

### What is the difference between internal and external setup?
Internal setup can only be done when the machine is stopped. External setup can be done while it is running.

### How do you measure changeover time?
From the last good product of the previous order to the first good product of the next order at normal speed.

### Does SMED really mean under ten minutes?
"Single-minute" means a single digit of minutes. It is a target; any reduction in internal time counts.

### Who should be involved in a SMED workshop?
Operators, a maintenance technician and a team leader. The people who do the changeover know where the time goes.
