# Changeover time reduction: SMED made repeatable with AR

> Changeover time reduction means shortening the time between the last good part of one run and the first good part of the next. SMED (Single-Minute Exchange of Die) is the classic method for this. Actarion makes the improved SMED sequence stick: operators follow it step by step with AR guidance, and every changeover is timed per step.

![A technician holds an iPad up to a robotic assembly line; the screen shows AR work instruction steps for changeover time reduction](/images/use-cases-changeover-smed-1600.webp)

## Why do changeovers stay long after a SMED project?

- The SMED workshop delivered a better sequence, but each shift still does it its own way.
- External tasks, which can be done while the machine runs, still happen during the stop.
- Nobody knows which step causes the variation, because times are not recorded.
- The best changeover operator is on holiday and the line waits.

## What do you measure?

| KPI | Definition |
|---|---|
| Changeover time | Last good part to first good part |
| Spread between shifts | Difference between fastest and slowest changeover |
| Internal vs external time | Share of work done while the machine is stopped |
| Start-up scrap | Rejects in the first minutes after the changeover |
| OEE availability | Effect of changeovers on uptime |

## How does an AR-guided changeover work?

1. **Run a SMED analysis** of the current changeover. Separate internal tasks (machine stopped) from external tasks (machine running).
2. **Move and simplify:** shift as much work as possible to external and standardize tools and settings.
3. **Digitize the new sequence.** AI turns the SMED result into steps with photos, settings and checks.
4. **Prepare before the stop.** The operator works through the external checklist while the previous run finishes.
5. **Execute with AR.** During the stop, each step shows on the machine, including settings and torque values.
6. **Analyze step times.** The data shows which steps vary, so the next improvement round is based on facts.

## FAQ

### What is SMED?
SMED is a method developed by Shigeo Shingo to cut changeover time, ideally to under ten minutes. It separates internal from external tasks and then shortens both.

### Do we need to run a SMED project first?
It helps, but it is not required. Digitizing the current best practice already reduces variation. The step times then show where to improve.

### Does the timing feel like control to operators?
It can. We advise using the data at team level to improve the method, not to judge individuals.
