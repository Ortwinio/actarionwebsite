# Events en webinars over AR-werkinstructies

> Op de events van Actarion zie je AI-gegenereerde werkinstructies met AR-begeleiding in actie. We organiseren webinars, staan op vakbeurzen en verzorgen sessies op locatie waar je team een stap-voor-stap-instructie uitprobeert op een tablet of AR-bril. De komende data staan hieronder; je kunt ook een sessie op je eigen locatie aanvragen.

![Een technicus houdt een iPad voor een schakelkast; op het scherm verschijnen AR-werkinstructies voor webinar ar-werkinstructies](/images/resources-events-1600.webp)

## Waarom live zien?

- AR is lastig te beoordelen vanaf een video.
- Je team wil het zelf in handen hebben.
- Je wilt vragen stellen over je eigen proces.

## Hoe vraag je een sessie op locatie aan?

1. Stuur een aanvraag via het contactformulier, onderwerp Sales & Demo.
2. We kiezen samen een use case uit je eigen fabriek.
3. Je team probeert de instructie op tablet of AR-bril.

## Hoe Actarion helpt

- Live demo's op tablet en AR-bril, niet alleen slides.
- Voorbeelden uit je eigen sector: voeding, farma, maakindustrie.
- Een vervolgintake om je eerste use case in kaart te brengen.
