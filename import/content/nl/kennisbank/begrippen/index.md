# Begrippenlijst: werkvloer-, kwaliteits- en AR-termen uitgelegd

> Deze begrippenlijst legt de termen uit die productie-, kwaliteits- en HSE-teams dagelijks gebruiken, van SOP en SMED tot LOTO, GMP en augmented reality. Elk begrip krijgt een korte definitie, een voorbeeld van de werkvloer en verwante termen. Actarion gebruikt deze begrippen om SOP's om te zetten in digitale werkinstructies met AR.

![Pentekening van een open begrippenboek met een cyaan bladwijzer](/img/illustraties/resources-glossary.svg)

## Waarom een gedeelde woordenschat?

- Productie, kwaliteit en IT bedoelen met hetzelfde woord iets anders.
- Nieuwe medewerkers verdrinken op dag één in afkortingen.

## Welke begrippen staan erin?

| Begrip | In één zin |
|---|---|
| [SOP](/nl/kennisbank/begrippen/sop/) | Een SOP is een beheerst document dat de standaardwerkwijze van een proces beschrijft. |
| [werkinstructie](/nl/kennisbank/begrippen/werkinstructie/) | Een werkinstructie is een document dat een operator precies vertelt hoe hij één taak stap voor stap uitvoert. |
| [connected worker](/nl/kennisbank/begrippen/connected-worker/) | Een connected worker is een medewerker in de uitvoering die tijdens het werk digitaal verbonden is met instructies, systemen en collega's. |
| [SMED](/nl/kennisbank/begrippen/smed/) | SMED is een lean-methode van Shigeo Shingo om omsteltijd te verkorten. |
| [OEE](/nl/kennisbank/begrippen/oee/) | OEE is een KPI die toont welk deel van de geplande productietijd goede output op volle snelheid oplevert. |
| [poka-yoke](/nl/kennisbank/begrippen/poka-yoke/) | Poka-yoke is Japans voor 'fouten voorkomen'. |
| [competentiematrix](/nl/kennisbank/begrippen/competentiematrix/) | Een competentiematrix, ook skills matrix of kwalificatiematrix, is een overzicht van mensen tegenover taken, met per persoon het niveau per taak. |
| [LOTO](/nl/kennisbank/begrippen/loto/) | LOTO is een procedure om energiebronnen (elektrisch, pneumatisch, hydraulisch, mechanisch, thermisch) af te schakelen en te borgen met sloten en labels voordat het werk begint. |
| [lijnvrijgave](/nl/kennisbank/begrippen/lijnvrijgave/) | Lijnvrijgave is een controle tussen batches die bevestigt dat al het vorige product, componenten, etiketten en documenten van de lijn zijn verwijderd. |
| [GMP](/nl/kennisbank/begrippen/gmp/) | GMP is een kwaliteitssysteem voor productie, vastgelegd in regelgeving zoals EU-GMP (EudraLex Volume 4) en in de VS 21 CFR Parts 210/211. |
| [CAPA](/nl/kennisbank/begrippen/capa/) | CAPA is een gestructureerd proces voor corrigerende maatregelen (een bestaand probleem oplossen) en preventieve maatregelen (een mogelijk probleem voorkomen). |
| [first time right](/nl/kennisbank/begrippen/first-time-right/) | First time right is een kwaliteits-KPI: het deel van de output dat bij de eerste poging aan de eisen voldoet. |
| [augmented reality](/nl/kennisbank/begrippen/augmented-reality/) | Augmented reality is technologie die computerbeelden toevoegt aan een live beeld van de fysieke omgeving, verankerd aan echte objecten. |
| [mixed reality](/nl/kennisbank/begrippen/mixed-reality/) | Mixed reality is een vorm van extended reality waarin virtuele objecten ruimtelijk aan de echte omgeving zijn gekoppeld en erop reageren. |
| [slimme bril](/nl/kennisbank/begrippen/slimme-bril/) | Een slimme bril is een op het hoofd gedragen display met camera en sensoren dat informatie in of naast het gezichtsveld toont. |
| [remote assistentie](/nl/kennisbank/begrippen/remote-assistentie/) | Remote assistentie (ook remote expert support) is een videoverbinding tussen een medewerker op de werkvloer en een expert, verrijkt met tekeningen of AR-markeringen in het beeld van de medewerker. |
| [kennisborging](/nl/kennisbank/begrippen/kennisborging/) | Kennisborging is het systematisch vastleggen van vaardigheden, ervaring en impliciete kennis van experts in een herbruikbare vorm. |
| [digital twin](/nl/kennisbank/begrippen/digital-twin/) | Een digital twin is een digitaal model van een fysiek object of systeem dat er via data mee verbonden is, zodat het model de actuele toestand weergeeft. |
| [MES](/nl/kennisbank/begrippen/mes/) | Een MES is een informatiesysteem dat de omzetting van grondstoffen naar eindproduct realtime volgt en vastlegt. |
| [Werkerassistenzsystem](/nl/kennisbank/begrippen/werkerassistenzsystem/) | Een Werkerassistenzsystem is een digitaal systeem dat medewerkers tijdens handwerk ondersteunt met informatie en controles die passen bij de situatie. |
