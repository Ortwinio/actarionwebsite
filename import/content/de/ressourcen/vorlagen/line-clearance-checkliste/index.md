# Line-Clearance-Checkliste: GMP-Vorlage für den Chargenwechsel

> Eine Line-Clearance-Checkliste bestätigt, dass eine Produktions- oder Verpackungslinie frei von Material, Etiketten, Produkt und Dokumenten der vorherigen Charge ist, bevor die nächste startet. Line Clearance (Linienräumung) verhindert Verwechslungen, eine Hauptursache für Rückrufe in Pharma und Lebensmitteln. Diese kostenlose Checkliste umfasst Räumung, Reinigung, linienspezifische Kontrollen und unabhängige QS-Freigabe.

![Federzeichnung: leere Verpackungslinie mit einem markierten zurückgebliebenen Karton, Klemmbrett und Tablet mit der Line-Clearance-Checkliste](/img/illustraties/resources-templates-line-clearance-checklist.svg)

## Warum passieren trotzdem Verwechslungen?

- Ein übrig gebliebener Beipackzettel oder eine Etikettenrolle landet in der nächsten Charge.
- Versteckte Stellen (Ausschussbehälter, unter Führungen, im Zuführer) werden nicht geprüft.
- Die Checkliste wird am Schichtende unterschrieben, nicht an der Linie.
- Die Zweitkontrolle ist eine Unterschrift, keine echte Prüfung.

## Was ist Line Clearance und wann ist sie vorgeschrieben?

Line Clearance ist die dokumentierte Prüfung, dass eine Linie frei von allem aus dem vorherigen Arbeitsgang ist. Der EU-GMP-Leitfaden (Teil I, Kapitel 5) fordert, dass Arbeitsbereiche und Ausrüstung vor Arbeitsbeginn frei von nicht benötigten Materialien, Produkten und Dokumenten sind; in Deutschland ist er über die AMWHV verbindlich. In den USA verlangt 21 CFR 211.130 die Inspektion von Verpackungsbereichen unmittelbar vor Gebrauch. Durchzuführen bei jedem Chargen- oder Produktwechsel und nach Instandhaltung.

## Die Line-Clearance-Checkliste

**Kopfdaten**

| Feld | Eintrag |
|---|---|
| Linie / Raum | |
| Vorheriges Produkt / Ch.-B. | |
| Folgeprodukt / Ch.-B. | |
| Datum / Beginn | |
| Durchgeführt von (Bediener) | |
| Verifiziert von (QS / zweite Person) | |

**1. Räumung der vorherigen Charge**

- [ ] Alle Fertigware entfernt und bilanziert
- [ ] Alle Restkomponenten (Bulk, Blister, Flaschen, Verschlüsse) entfernt
- [ ] Alle Packmittel mit Aufdruck (Etiketten, Beipackzettel, Faltschachteln) entfernt und bilanziert
- [ ] Ausschuss- und Musterbehälter geleert
- [ ] Alle Chargendokumente der vorherigen Charge entfernt

**2. Linienspezifische Kontrollen**

| Nr. | Stelle | Prüfung | i.O. | n.i.O. | Bemerkung |
|---|---|---|---|---|---|
| 1 | Zuführung / Trichter | Leer, kein Produkt | [ ] | [ ] | |
| 2 | Förderbänder und Führungen | Kein Produkt, keine Komponenten, auch darunter | [ ] | [ ] | |
| 3 | Etikettierer / Drucker | Keine alten Etiketten; Druck auf neue Charge eingestellt | [ ] | [ ] | |
| 4 | Beipackzettel- / Faltschachtelzuführung | Leer | [ ] | [ ] | |
| 5 | Kamera- / Prüfsysteme | Auf neues Produkt eingestellt, getestet | [ ] | [ ] | |
| 6 | Ausschleusung | Leer | [ ] | [ ] | |
| 7 | Boden, Tische, Abfallbehälter | Frei von Produkt und Packmitteln | [ ] | [ ] | |

**3. Reinigung und Status**

- [ ] Linie nach Reinigungs-SOP gereinigt; Reinigungsprotokoll unterschrieben
- [ ] Statuskennzeichnung auf "gereinigt / geräumt" geändert
- [ ] Formatteile für Folgeprodukt montiert und geprüft

**4. Freigabe**

- [ ] Material für Folgecharge angeliefert und gegen Herstellanweisung geprüft
- [ ] Abzeichnung Bediener ______ Uhrzeit ______
- [ ] Unabhängige Verifizierung (QS) ______ Uhrzeit ______
- [ ] Linie freigegeben für Charge ______

## Wie füllen Sie die Checkliste aus?

1. **Linienspezifisch machen.** Ersetzen Sie Abschnitt 2 durch jede Stelle Ihrer Linie, an der Produkt oder Packmittel verbleiben können, mit Fotos.
2. **Packmittel bilanzieren.** Ausgegebene, verbrauchte, vernichtete und zurückgegebene Etiketten zählen. Differenzen vor Freigabe untersuchen.
3. **Erst prüfen, dann unterschreiben.** An der Linie, Schritt für Schritt, mit Uhrzeit. Nachträgliches Abzeichnen verletzt die Datenintegrität (ALCOA+).
4. **Unabhängige Zweitkontrolle.** QS oder eine geschulte zweite Person prüft physisch und zeichnet nicht nur gegen.
5. **n.i.O. = Stopp.** Jede Abweichung blockiert die Freigabe, bis sie behoben und dokumentiert ist.

## Häufige Fragen

### Was ist Line Clearance in der Pharmaindustrie?
Die dokumentierte Prüfung, dass eine Linie frei von allen Materialien, Produkten und Dokumenten der vorherigen Charge ist, bevor eine neue Charge beginnt.

### Wer führt die Line Clearance durch?
Der Bediener führt sie durch; QS oder eine geschulte zweite Person verifiziert sie vor der Freigabe unabhängig.

### Wann ist Line Clearance erforderlich?
Bei jedem Chargen- oder Produktwechsel, nach Instandhaltung an der Linie und nach der Reinigung.

### Gibt es Line Clearance auch in der Lebensmittelindustrie?
Ja. Sie verhindert dort Allergen- und Etikettenverwechslungen.
