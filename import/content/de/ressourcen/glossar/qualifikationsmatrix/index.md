# Was ist eine Qualifikationsmatrix? Beispiel

> Eine Qualifikationsmatrix (Skills Matrix) ist eine Tabelle, die zeigt, welche Mitarbeitenden für welche Tätigkeiten oder Anlagen qualifiziert sind und auf welchem Niveau. Sie unterstützt Schichtplanung, Schulung und Audits. Actarion hält die Qualifikationsmatrix in der DeepSight-Konsole aktuell, auf Basis echter Ausführungen digitaler Arbeitsanweisungen.

![Ein Techniker hält ein iPad vor eine Produktionshalle; auf dem Bildschirm erscheinen AR-Arbeitsanweisungen für was ist eine qualifikationsmatrix](/images/resources-glossary-skills-matrix-1600.webp)

## Warum ist das in der Fertigung wichtig?

- Die Matrix ist eine veraltete Tabelle auf einem einzigen Laptop.
- Lücken fallen erst auf, wenn jemand krank ist.

## Was ist eine Qualifikationsmatrix?

Eine Qualifikationsmatrix, auch Kompetenzmatrix oder Skills Matrix, stellt Personen und Tätigkeiten gegenüber und zeigt je Person das Niveau pro Tätigkeit.

Die Stufen reichen meist von „in Einarbeitung“ bis „kann andere schulen“. Die Matrix zeigt Engpässe, Schulungsbedarf und wer eine Tätigkeit freigeben darf. Auditoren fragen häufig danach.

## Kernelemente

1. Tätigkeiten oder Anlagen als Spalten
2. Mitarbeitende als Zeilen
3. Je Zelle eine klare Stufe mit Datum

## Beispiel aus der Praxis

Eine Teamleiterin sieht, dass nur zwei Werker Linie 3 rüsten können. Sie plant für diesen Monat geführte Rüstvorgänge für einen dritten Kollegen.

## Wie unterstützt Actarion?

- Digitale Schritt-für-Schritt-Arbeitsanweisungen, per KI aus Ihren SOPs erstellt.

## Häufige Fragen

### Welche Stufen nutzt eine Qualifikationsmatrix?

Oft vier: lernt, mit Hilfe, selbstständig, kann andere schulen.

### Wie oft wird sie aktualisiert?

Laufend, mindestens nach jeder Schulung oder Qualifizierung.

### Ist eine Qualifikationsmatrix für ISO 9001 Pflicht?

ISO 9001 fordert Kompetenznachweise; die Matrix ist ein gängiger Weg, sie zu erbringen.
