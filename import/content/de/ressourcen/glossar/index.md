# Glossar: Begriffe aus Fertigung, Qualität und AR erklärt

> Dieses Glossar erklärt Begriffe, die Produktions-, Qualitäts- und Arbeitsschutzteams täglich nutzen, von SOP und SMED bis LOTO, GMP und Augmented Reality. Jeder Eintrag bietet eine kurze Definition, ein Praxisbeispiel und verwandte Begriffe. Actarion nutzt diese Konzepte, um SOPs in digitale Arbeitsanweisungen mit AR-Werkerführung umzuwandeln.

![Federzeichnung eines offenen Glossarbuchs mit cyanfarbenem Lesezeichen](/img/illustraties/resources-glossary.svg)

## Warum ein gemeinsames Vokabular?

- Produktion, Qualität und IT meinen mit demselben Wort Verschiedenes.
- Neue Mitarbeitende ertrinken am ersten Tag in Abkürzungen.

## Welche Begriffe sind enthalten?

| Begriff | In einem Satz |
|---|---|
| [SOP](/de/ressourcen/glossar/sop/) | Eine SOP ist ein gelenktes Dokument, das die Standardvorgehensweise eines Prozesses beschreibt. |
| [Arbeitsanweisung](/de/ressourcen/glossar/arbeitsanweisung/) | Eine Arbeitsanweisung ist ein Dokument, das einem Werker genau sagt, wie er eine Tätigkeit Schritt für Schritt ausführt. |
| [Connected Worker](/de/ressourcen/glossar/connected-worker/) | Ein Connected Worker ist ein Mitarbeiter, der bei der Arbeit digital mit Anweisungen, Systemen und Kollegen verbunden ist. |
| [SMED](/de/ressourcen/glossar/smed/) | SMED ist eine von Shigeo Shingo entwickelte Lean-Methode zur Rüstzeitminimierung. |
| [OEE](/de/ressourcen/glossar/oee/) | OEE ist eine Kennzahl, die zeigt, welcher Anteil der geplanten Produktionszeit Gutteile in voller Geschwindigkeit liefert. |
| [Poka-Yoke](/de/ressourcen/glossar/poka-yoke/) | Poka-Yoke ist Japanisch für „unglückliche Fehler vermeiden“. |
| [Qualifikationsmatrix](/de/ressourcen/glossar/qualifikationsmatrix/) | Eine Qualifikationsmatrix, auch Kompetenzmatrix oder Skills Matrix, stellt Personen und Tätigkeiten gegenüber und zeigt je Person das Niveau pro Tätigkeit. |
| [LOTO](/de/ressourcen/glossar/loto/) | LOTO ist ein Verfahren, um Energiequellen (elektrisch, pneumatisch, hydraulisch, mechanisch, thermisch) abzuschalten und mit Schlössern und Anhängern zu sichern, bevor die Arbeit beginnt. |
| [Line Clearance](/de/ressourcen/glossar/line-clearance/) | Line Clearance ist ein Prüfschritt zwischen Chargen, der bestätigt, dass alle vorherigen Produkte, Komponenten, Etiketten und Unterlagen von der Linie entfernt sind. |
| [GMP](/de/ressourcen/glossar/gmp/) | GMP ist ein Qualitätssystem für die Herstellung, festgelegt etwa im EU-GMP-Leitfaden (EudraLex Band 4) und in den USA in 21 CFR Parts 210/211. |
| [CAPA](/de/ressourcen/glossar/capa/) | CAPA ist ein strukturierter Prozess für Korrekturmaßnahmen (bestehendes Problem beheben) und Vorbeugemaßnahmen (mögliches Problem vermeiden). |
| [First Time Right](/de/ressourcen/glossar/first-time-right/) | First Time Right ist eine Qualitätskennzahl: der Anteil der Leistung, der beim ersten Versuch die Anforderungen erfüllt. |
| [Augmented Reality](/de/ressourcen/glossar/augmented-reality/) | Augmented Reality ist Technik, die computergenerierte Inhalte einem Livebild der physischen Umgebung hinzufügt, verankert an realen Objekten. |
| [Mixed Reality](/de/ressourcen/glossar/mixed-reality/) | Mixed Reality ist eine Form von Extended Reality, bei der virtuelle Objekte räumlich an die reale Umgebung gebunden sind und auf sie reagieren. |
| [Datenbrille](/de/ressourcen/glossar/datenbrille/) | Eine Datenbrille ist ein am Kopf getragenes Display mit Kamera und Sensoren, das Informationen im oder neben dem Sichtfeld darstellt. |
| [Remote-Assistenz](/de/ressourcen/glossar/remote-assistenz/) | Remote-Assistenz (auch Remote-Experten-Support) ist eine Videoverbindung zwischen einem Mitarbeiter vor Ort und einem Experten, ergänzt um Zeichnungen oder AR-Markierungen im Sichtfeld des Mitarbeiters. |
| [Wissenserfassung](/de/ressourcen/glossar/wissenserfassung/) | Wissenserfassung ist das systematische Festhalten von Fertigkeiten, Erfahrung und implizitem Wissen von Experten in wiederverwendbarer Form. |
| [digitaler Zwilling](/de/ressourcen/glossar/digitaler-zwilling/) | Ein digitaler Zwilling ist ein digitales Modell eines physischen Objekts oder Systems, das über Daten mit ihm verbunden ist und so dessen aktuellen Zustand abbildet. |
| [MES](/de/ressourcen/glossar/mes/) | Ein MES ist ein Informationssystem, das die Umwandlung von Rohstoffen in Fertigprodukte in Echtzeit verfolgt und dokumentiert. |
| [Werkerassistenzsystem](/de/ressourcen/glossar/werkerassistenzsystem/) | Ein Werkerassistenzsystem ist ein digitales System, das Beschäftigte bei manueller Arbeit mit situationsgerechten Informationen und Prüfungen unterstützt. |
