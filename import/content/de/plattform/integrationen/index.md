# Integrationen mit SAP, MES und LMS für Arbeitsanweisungen

> Die Integration von Arbeitsanweisungen bedeutet Datenaustausch zwischen Ihren digitalen Arbeitsanweisungen und vorhandenen Systemen wie ERP (zum Beispiel SAP), MES, LMS oder BI-Tools. Die Actarion-Plattform bietet CSV-Export und API-Anbindungen. Welche Systeme Sie wie anbinden, legen wir je Projekt im Pilotprojekt fest.

![Ein Techniker hält ein iPad vor eine Leitwarte; auf dem Bildschirm erscheinen AR-Arbeitsanweisungen für Integration Arbeitsanweisungen](/images/platform-integrations-1600.webp)

## Warum erzeugen Insellösungen Mehraufwand?

- Werker tippen dieselbe Auftragsnummer in drei Systeme.
- Schulungsnachweise im LMS passen nicht zu dem, wer die Arbeit wirklich macht.
- Ausführungsdaten bleiben in einem eigenen Tool und werden nie mit OEE- oder Qualitätsdaten kombiniert.
- Die IT blockiert neue Software, die nicht in die Architektur passt.

## Was lässt sich anbinden?

Die Tabelle zeigt typische Ziele. Die verfügbare Anbindung je System bestätigen wir im Scoping.

| System | Typisches Ziel | Status |
|---|---|---|
| BI (zum Beispiel Power BI) | Ausführungs- und Abweichungsdaten auswerten | API und CSV-Export verfügbar |
| ERP (zum Beispiel SAP) | Anweisung aus Fertigungs- oder Instandhaltungsauftrag starten; Ergebnis zurückmelden | [TE BEVESTIGEN: Standard-SAP-Konnektor oder API-Projekt] |
| MES | Anweisungen mit Auftrag, Produkt oder Arbeitsplatz verknüpfen | [TE BEVESTIGEN: MES-Integrationsoptionen] |
| LMS / HR | Qualifikationen, Schulungen und Zertifikate synchronisieren | [TE BEVESTIGEN: LMS-Integrationsoptionen] |
| Identität (SSO) | Anmeldung mit Firmenkonten | [TE BEVESTIGEN: SSO-Unterstützung] |

## Wie läuft ein Integrationsprojekt ab?

1. **Ziel festlegen.** Welche Daten müssen wohin, und warum? Ausgangspunkt sind die Pilot-KPIs.
2. **Optionen prüfen.** Export, API oder fertiger Konnektor, je System.
3. **Einfach beginnen.** Viele Pilotprojekte starten mit CSV-Export. Das belegt den Nutzen, bevor mehr gebaut wird.
4. **Bauen und testen.** Ihre IT oder Ihr Integrator bindet über die API an; Actarion unterstützt.
5. **Betreiben und überwachen.** Datenflüsse werden im Rahmen der Skalierung geprüft.

## Welchen Nutzen hat jede Rolle?

| Rolle | Nutzen |
|---|---|
| Werker | Weniger Doppelerfassung; die richtige Anweisung öffnet sich zum Auftrag |
| Schichtleiter | Ein Bild von Ausbringung, Abweichungen und Qualifikationen |
| Qualität / Arbeitssicherheit | Ausführungsdaten neben Qualitäts- und Chargendaten |
| Personal / Weiterbildung | Qualifikationen und Schulungsnachweise synchron |
