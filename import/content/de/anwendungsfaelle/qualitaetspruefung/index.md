# Digitale Prüfcheckliste: Fehler an der Quelle finden

> Eine digitale Prüfcheckliste ersetzt das Papierformular durch geführte Prüfungen auf Tablet oder AR-Brille. Actarion erstellt die Checkliste aus Ihrem Prüfplan, zeigt jedes Prüfmerkmal am Produkt und erfasst je Schritt Messwerte, Fotos und i.O./n.i.O. Die Qualitätssicherung erhält vollständige, durchsuchbare Daten statt abgehakter Kästchen.

![Ein Smartphone vor eine Förderanlage zeigt AR-Schritte und eine bestätigte Prüfung für digitale prüfcheckliste](/images/use-cases-quality-inspections-1600.webp)

## Was ist an Papierprüfungen falsch?

- Kästchen werden abgehakt, ohne dass wirklich geprüft wurde.
- Messwerte werden notiert, aber nie ausgewertet.
- Prüfer legen Kriterien unterschiedlich aus, die Ergebnisse schwanken je Schicht.
- Im Audit dauert die Suche nach dem richtigen Formular Stunden.

## Was messen Sie?

| KPI | Aussage |
|---|---|
| Fehler an der Quelle gefunden | Fehler, die vor dem Kunden gestoppt werden |
| Vollständigkeit der Prüfungen | Anteil der Prüfungen mit gültigem Ergebnis |
| Zeit je Prüfung | Effizienz des Prüfers |
| Kundenreklamationen | Endergebnis besserer Prüfungen |

## Wie funktioniert eine digitale Qualitätsprüfung?

1. **Prüfplan umwandeln.** Die KI erstellt Schritte aus Ihrem Control Plan oder Ihrer Papier-Checkliste.
2. **Kriterien festlegen.** Jeder Schritt hat einen Grenzwert, ein Referenzfoto oder eine i.O./n.i.O.-Regel.
3. **Prüfer führen.** AR zeigt, wo gemessen wird und wie ein Gutteil aussieht.
4. **Nachweise erfassen.** Werte, Fotos und Bemerkungen werden mit Zeit und Prüfer gespeichert.
5. **Abweichungen behandeln.** Eine n.i.O.-Prüfung löst eine Sperre oder Folgemaßnahme aus.
6. **Trends auswerten.** Das Dashboard zeigt, welche Prüfungen am häufigsten fehlschlagen.

## Welche Ergebnisse können Sie erwarten?

Zuverlässigere Prüfungen, weniger Unterschiede zwischen Prüfern und Audit-Nachweise auf Knopfdruck. Kundenwerte: `[CIJFER TE BEVESTIGEN]`. Anonymisierte Projekte aus Bergbau, Lebensmittel und Pharma umfassten jeweils Prüfungen oder Bewertungen ([zu den Projekten](/de/kunden/)).

## Welche Hardware brauchen Sie?

- **Tablet** für die meisten Prüfungen.
- **AR-Brille** für große Objekte oder Prüfungen, die beide Hände erfordern.
- Optional: angebundene Messmittel `[TE BEVESTIGEN: koppeling meetmiddelen]`.

## So starten Sie ein Pilotprojekt

Nehmen Sie eine Prüfung mit vielen Befunden oder Auditanmerkungen. Laden Sie unsere [Checkliste Qualitätsprüfung](/de/ressourcen/vorlagen/qualitaetspruefung-checkliste/) herunter, füllen Sie sie für Ihr Produkt aus, und wir digitalisieren sie. [Pilotprojekt planen](/de/pilotprojekt/).

## Typische Fehler im Pilotprojekt

- **Das Papierformular eins zu eins übernehmen.** Nutzen Sie den Umstieg, um ungenutzte Prüfungen zu streichen und Toleranzen und Fotos dort zu ergänzen, wo sie zählen.
- **Keine klare Regel für Abweichungen.** Legen Sie vor dem Start fest, was passiert, wenn ein Wert außerhalb der Toleranz liegt.
- **Die Messmittel vergessen.** Entscheiden Sie, ob Werte eingetippt werden oder aus angebundenen Messmitteln kommen `[TE BEVESTIGEN: koppeling meetmiddelen]`.

## So unterstützt Actarion

- Die KI macht aus Ihrem Prüfplan eine geführte digitale Checkliste.
- Referenzfotos und AR-Markierungen machen Kriterien eindeutig.
- Jedes Ergebnis wird für Rückverfolgbarkeit und Audits protokolliert.
- Trenddaten zeigen, wo Sie den Prozess verbessern können.
