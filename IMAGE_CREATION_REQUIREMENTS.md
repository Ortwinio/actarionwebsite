## Image Generation Prompts

Use these prompts with AI image generators (Midjourney, DALL-E, Stable Diffusion):

### Base Prompt Template
```
Flat vector illustration, industrial manufacturing setting, teal and cyan color palette 
with orange accent highlights, clean modern style, 16:9 aspect ratio, professional 
industrial setting with AR overlay elements
```

### Example: Assembly Mistakes Prevention
```
Flat vector illustration, manufacturing worker in teal hard hat at assembly workstation, 
split view showing wrong assembly with red X mark and correct assembly with green checkmark, 
AR tablet displaying checklist, orange warning triangles, component parts on workbench, 
teal and cyan color palette, clean modern style --ar 16:9
```

### Example: Remote Expert Support
```
Flat vector illustration, field technician wearing AR smart glasses, small video window 
showing remote expert face, orange AR annotations pointing to industrial equipment, 
troubleshooting scene, clock showing fast resolution, teal and navy blue colors 
with orange accents --ar 16:9
```
